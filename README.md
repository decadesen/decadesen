# Decadesen

我做个人工具，也用网页试验不同的交互方式。

## 可以体验

**[Decadesen · 3D 驾驶主页](https://decadesen.cn/)**  
开车探索营地、撞散路边的字牌，或者去赛道跑一圈。驾驶世界移植自 [Bruno Simon 的开源作品](https://github.com/brunosimon/folio-2025)，公开入口和站点导航按 Decadesen 的内容组织。

[Space](https://space.decadesen.cn/) · [文章](https://blog.decadesen.cn/)

## 代码实验

| 项目 | 可以从哪里开始 |
| --- | --- |
